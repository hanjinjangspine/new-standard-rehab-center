## 이미지 원칙과 출처

- 병원 사진은 새기준병원 공식 홈페이지 저장소의 공개 홍보 자산을 사용했습니다.
- 직원·의료진 사진은 실제 치료 결과나 환자 사례로 표현하지 않고 병원 안내와 진료 연계 영역에만 배치했습니다.
- 부족한 이미지는 2026-09-01 OpenAI 이미지 생성으로 제작한 무인 환경·사물 연출 이미지입니다. 사람, 환자, 로고, 의료 성과 표현은 포함하지 않았습니다.
- 생성 이미지에는 실제 치료 장면으로 오해되지 않도록 사실형 대체텍스트에 `연출 이미지`를 명시했습니다.
- 생성 원본은 WebP 품질 86으로 변환해 페이지 전송량을 줄였습니다.
